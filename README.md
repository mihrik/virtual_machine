# Виртуальная машина

Стековая виртуальная машина и двухпроходный ассемблер, переводящий авторский язык в байт код.
Процессор имеет собственный набор регистров, оперативную память и видеопамять.

## Возможности

- Арифметические операции: сложение, умножение, деление, вычитание и извлечение корня.
- Работа с регистрами и оперативной памятью. Доступные регистры: [A-I]X
- Условные и безусловные переходы.
- Именованные метки.
- Вызов подпрограмм и выход из них.
- Тьюринг-полнота.
- Ввод и вывод чисел. Распечатка видеопамяти в консоль.
- Собственный язык поддерживает комментарии и пустые строки.

## Авторские фичи

- Проверка корректного выполнения операций со стеком после каждого действия с ним.
- Поиск команд и регистров бинарным поиском по отсортированным хэшам.
- Тестировочные программы: подсчет факториала натурального числа, не превышающего 12, решение квадратного уравнения по введенным коэффициентам, вывод в консоль кружочка по заданному радиусу.
- Команда PUSH является универсальной для операции с регистрами, оперативной памятью и числами, программа анализирует их комбинацию с помощью байта операции, первые пять бит которого значат номер команды, 6 бит = 1, если в строке есть число, 7 аналогично, если регистр, 8 бит аналогично, если результат должен быть взят из оперативной памяти.
- Приближенный к системному vm_dump в случае ошибки.

## Пример программы

--> commands.asm

PUSH 2
PUSH 3
ADD
OUT
HLT

## Запуск

g++ assembler.cpp assembler_funcs.cpp vm_funcs.cpp stack_funcs.cpp -o asm
./asm commands.asm - результат компиляции записан в compiled.bin
g++ vm.cpp vm_funcs.cpp stack_funcs.cpp -o main
./main compiled.bin

## Команды собственного языка программирования

- PUSH - кладет в стек процессора значение регистра, числа, значения из оперативной памяти или их комбинации.
- ADD - складывает два последних элемента стека и кладет результат в стек.
- SUB - находит разность предпоследнего и последнего элементов стека и кладет результат в стек.
- DIV - находит частное предпоследнего и последнего элементов стека и кладет результат в стек.
- OUT - выводит значение последнего элемента стека в консоль.
- POPr - кладет значение последнего элемента стека в указанный регистр.
- MUL - находит произведение предпоследнего и последнего элементов стека и кладет результат в стек.
- JMP - ставит ip в указанный адрес.
- JA - проверяет если предпоследний элемент стека больше чем последний и в случае успеха ставит ip в указанный адрес.
- JAE - проверяет если предпоследний элемент стека больше или равен последнему и в случае успеха ставит ip в указанный адрес.
- JB - проверяет если предпоследний элемент стека меньше чем последний и в случае успеха ставит ip в указанный адрес.
- JBE - проверяет если предпоследний элемент стека меньше или равен последнему и в случае успеха ставит ip в указанный адрес.
- JE - проверяет если предпоследний элемент стека равен последнему и в случае успеха ставит ip в указанный адрес.
- JNE - проверяет если предпоследний элемент стека не равен последнему и в случае успеха ставит ip в указанный адрес.
- IN - получает число из пользовательского ввода и пушит его в стек.
- CALL - ставит ip в указанный адрес и запоминает в функциональный стек адрес возврата сразу после вызова CALL.
- RET - ставит ip в значение последнего числа в функциональном стеке.
- SQRT - находит квадратный корень из последнего числа стека и кладет его в стек.
- POPm - кладет последнее значение стека по указанному адресу в оперативную память.
- DRAW - печатает на экран распечатку видеопамяти.
- POPmr - кладет значение указанного регистра по указанному адресу в оперативную память.
- HLT - завершает выполнение программы, уничтожает стек.
